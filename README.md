# 手書きカレンダー

iPad の Safari で動く、**Google カレンダーに Apple Pencil で手書きできる** Web アプリです。
紙の手帳のように、月・週・日のページへ自由に書き込めます。書いた文字を囲むと、そのまま Google カレンダーの予定として登録できます。

- 公開先（予定）: <https://syfan0-star.github.io/tegaki-calendar/>
- Google とつなぐ設定: [docs/SETUP.md](docs/SETUP.md)

## できること

| 機能 | 内容 |
| --- | --- |
| 予定の表示 | Google カレンダーの予定を **日・週・月** の 3 種類のページで表示（祝日は赤字） |
| 手書き | Apple Pencil の筆圧で太さが変わるペン（6 色・3 段階の太さ）、マーカー（4 色）、消しゴム |
| 手書きの保存 | 書いた内容は端末にすぐ保存され、Google ドライブ（アプリ専用の非表示フォルダ）にも自動で送られます。別の iPad でも同じ書き込みが見られます |
| 予定にする（なぞる） | 「予定」ツールで時間帯をなぞる → タイトル欄にペンで書く（iPad のスクリブル機能で文字に変わります） → 保存 |
| 予定にする（囲む） | 「投げなわ」で書いた文字を囲む → 「予定にする」 → 書いた位置から日時が入った画面が開く → タイトルを書いて保存 |
| 予定の編集 | 予定を **指でタップ** すると、編集・削除の画面が開きます |
| お試しモード | Google につながずに、見本の予定で操作を試せます（手書きはこの端末の中だけに保存） |

## 使い方のコツ

- **ペンは書く、指は動かす**：Apple Pencil で書き、指でページをスクロール・予定をタップします。手のひらが画面に触れても線は引かれません。
  Apple Pencil がないときは、設定の「指・マウスでも書く」をオンにします。
- **ページは表示ごとに別々**：月のページ、週のページ、日のページには、それぞれ別の書き込みができます（紙の手帳と同じです）。
- **元に戻す**：下のツールバーの ↶ / ↷ で、書く・消す・動かすを取り消し・やり直しできます。
- **日付へ移動**：月表示で日付の数字をタップ、週表示で上の日付をタップすると、その日のページに移ります。左右のスワイプでも前後へ移動できます。
- **ホーム画面に追加**：Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で使えます。
  Safari とホーム画面のアプリは中身が別扱いなので、ホーム画面から開いたら改めて Google にログインしてください。

## データの扱い

- 手書きは iPad の中（ブラウザのデータベース）と、Google ドライブの「アプリ専用の非表示フォルダ」に保存されます。
  ドライブの一覧には表示されず、他のファイルをこのアプリが見ることもありません。
- 予定は普通の Google カレンダーの予定として登録されます（他の人への通知は送りません）。
- Google との接続は安全のため約 1 時間で切れ、自動でつなぎ直します。つなぎ直せないときは画面上部に「Google に再接続」と出るので押してください。
  その間に書いたものも端末に保存されているので消えません。

## 開発者向け

ビルド不要の素の JavaScript（ES モジュール）です。外部ライブラリは使っていません。

```
index.html / styles/ / sw.js / manifest.webmanifest   画面の土台・オフライン対応
js/main.js            全体の組み立て
js/views/             日・週・月のページ描画と座標計算
js/ink/               手書き（入力・描画・データ構造）
js/data/              予定の取得（Google / お試し）と手書きの保存・同期
js/google/            Google へのログイン・API 呼び出し
js/ui/                ヘッダー・ツールバー・ダイアログ
docs/SPEC.md          設計書（モジュール間の約束事）
```

テスト（Node.js 24）:

```bash
npm test
```

ローカルで動かす:

```bash
python3 -m http.server 8000
```

（<http://localhost:8000/> を開く）
